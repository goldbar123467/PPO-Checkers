# Iteration 000023 — Prove same-stack deterministic PPO updates

## Objective

Implement the single D1 seeding entrypoint and run a complete ten-update fixture twice on CPU and
twice on the local RTX 5070, with no reuse of model, optimizer, sampled actions, or behaviour
log-probabilities between repeats.

## RED / corrections / GREEN

The suite began with a missing `determinism.py` import failure (`000088-*`). The behavioral pass
then proved the required traces, while the first quality run exposed strict typing and uncovered
validation paths (`000090-*`). The corrected focused gate passes 13 tests, strict Ruff/mypy, and
100% of 68 statements and 16 branches (`000091-*`).

## Result

- one root deterministically seeds Python, NumPy, Torch, all CUDA devices, and four distinct stable
  environment streams;
- two independently reconstructed ten-update CPU traces have exactly equal action and loss tuples;
- two independently reconstructed same-stack RTX traces have identical actions and loss metrics
  within `atol=1e-5, rtol=1e-4`;
- native CUDA BF16 masked sampling remains finite/legal and gives illegal logits exact-zero
  gradients;
- the evidence transcript pins GPU identity, driver, Python, PyTorch, CUDA, cuDNN, MKL, and all
  determinism flags. No cross-stack or bitwise-GPU claim is made.
