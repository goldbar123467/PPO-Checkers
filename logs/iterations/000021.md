# Iteration 000021 — Verify the exact GroupNorm policy/value network

## Objective

Implement N1–N7 literally, prove supervised head capacity and gradient reachability, and finally
run the logit-level aliasing regression that could not exist in Phase 4.

## RED / correction / GREEN

The architecture suite began with a missing-module collection failure (`000075-*`). The first
implementation passed 12/13 tests; a bitwise batch-composition assertion failed only in last-bit
floating accumulation. A second tolerance of `1e-7` was still too strict for the value head's
`1.49e-6` difference. The final test uses the already-declared D3 bounds (`atol=1e-5,
rtol=1e-4`) for different batch shapes and retains bitwise train/eval equality for the identical
batch (`000076-*` through `000078-*`).

The quality audit exposed formatting, strict PyTorch-stub casts, magic constants, and three
unexercisable optional-affine branches. The initialization helpers were narrowed to the project's
always-affine modules. The final strict gate passes 13 tests with 103/103 statements and 12/12
branches covered (`000080-*`).

## Results

- exact N2–N6 structure, six residual blocks, and no BatchNorm;
- output logits `(batch,128)`, values `(batch,)` bounded by tanh;
- orthogonal and zero-bias initialization matches declared gains;
- N7 mid-capture and same-placement boundary observations produce different logits;
- every parameter is graph-connected, each major module has nonzero aggregate gradient, and
  illegal action logits receive exact-zero gradient;
- frozen-feature T1 policy accuracy is 1.0 on 64 states;
- frozen-feature T2 value MSE is `4.69e-14` on 64 targets;
- 470,410 parameters occupy 1.794 MiB as FP32 weights.

Exact metrics are in `logs/test-output/000081-phase6-supervised-metrics.txt`. These tests prove
capacity and connectivity, not PPO correctness or learned checkers strength.
